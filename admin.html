Painel da loja

Altere dados da loja e produtos. Mudanças valem neste navegador; use "Baixar arquivos" para publicar de verdade.

1. Dados da loja

WhatsApp, Pix e backend do Mercado Pago.

Ex: 5586999999999
Deixe vazio até publicar a pasta server/

2. Produtos

Edite preço, descrição e o link de entrega (fileUrl) de cada produto.

3. Publicar alterações

O admin salva no navegador. Para valer para todos os clientes, baixe os arquivos e substitua no repositório (ou edite js/products.js e js/config.js direto no GitHub).

4. Pedidos via Pix feitos neste aparelho

Pedidos manuais registrados neste navegador (o cliente também te chama no WhatsApp).
